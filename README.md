# NYC Open Data Turntable

Prototype for [Data Through Design](https://datathroughdesign.com) 2027.

Run `python3 -m http.server` in this folder and open http://localhost:8000.

## Data

- [Local Law 251 of 2017: Published Data Asset Inventory](https://data.cityofnewyork.us/City-Government/Local-Law-251-of-2017-Published-Data-Asset-Invento/5tqd-u88y/about_data)
- [NYC Open Data Help Desk: Data Questions and Reported Errors](https://data.cityofnewyork.us/City-Government/NYC-Open-Data-Help-Desk-Data-Questions-and-Reporte/r67x-e97r/about_data)
- [NYC Open Data Release Tracker](https://data.cityofnewyork.us/City-Government/NYC-Open-Data-Release-Tracker/qj2z-ibhs/about_data)

Source CSVs are in `data/source/`.
